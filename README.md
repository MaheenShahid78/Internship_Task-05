# Major Cities in Pakistan Population Prediction using Linear Regression

## Overview

This task focuses on predicting the 2017 population of major cities in Pakistan using **Linear Regression**. It demonstrates how historical population data and additional city information can be used to build, evaluate, and compare machine learning regression models.

Two models are developed in this task:

- Simple Linear Regression
- Multiple Linear Regression

The models are evaluated using **R² Score, Mean Absolute Error (MAE), and Root Mean Squared Error (RMSE)**.

The task also includes data visualization, coefficient analysis, model comparison, and population prediction for Peshawar.

---

## Objectives

- Load the population dataset using Pandas
- Select features and target variables
- Split the dataset into training and testing sets
- Build a Simple Linear Regression model
- Predict the 2017 population using the 1998 population
- Visualize the Simple Linear Regression results
- Evaluate the Simple Linear Regression model
- Prepare multiple features for Multiple Linear Regression
- Convert the Province column into numerical dummy variables
- Build a Multiple Linear Regression model
- Evaluate the Multiple Linear Regression model
- Compare Simple and Multiple Linear Regression
- Visualize actual vs predicted population
- Analyze model coefficients
- Predict the 2017 population of Peshawar
- Compare Peshawar's predicted population with its actual population

The **Change** feature has the largest raw coefficient in the model.

A negative coefficient means that the model's predicted population decreases as that feature increases, while the other features remain constant.

However, raw coefficient values should not be directly considered as feature importance because the features are measured on different scales.

# Evaluation Metrics

## R² Score

R² measures how well the model explains the variation in the target variable.

A higher R² value generally indicates better model performance.

## Mean Absolute Error (MAE)

MAE measures the average absolute difference between the actual and predicted values.

A lower MAE indicates smaller prediction errors.

## Root Mean Squared Error (RMSE)

RMSE measures the prediction error while giving more weight to larger errors.

A lower RMSE indicates better prediction performance.
