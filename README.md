# Major Cities in Pakistan Population Prediction using Linear Regression

## Overview

This project focuses on predicting the 2017 population of major cities in Pakistan using **Linear Regression**. It demonstrates how historical population data and additional city information can be used to build, evaluate, and compare machine learning regression models.

Two models are developed in this task:

- Simple Linear Regression
- Multiple Linear Regression

The models are evaluated using **R² Score, Mean Absolute Error (MAE), and Root Mean Squared Error (RMSE)**.

The project also includes data visualization, coefficient analysis, model comparison, and population prediction for Peshawar.

---

## Objectives

- Load the population dataset using Pandas
- Select features and target variables
- Split the dataset into training and testing sets
- Build a Simple Linear Regression model
- Predict the 2017 population using the 1998 population
- Visualize the Simple Linear Regression results
- Evaluate the Simple Linear Regression model
- Prepare multiple features for Multiple Linear Regression
- Convert the Province column into numerical dummy variables
- Build a Multiple Linear Regression model
- Evaluate the Multiple Linear Regression model
- Compare Simple and Multiple Linear Regression
- Visualize actual vs predicted population
- Analyze model coefficients
- Predict the 2017 population of Peshawar
- Compare Peshawar's predicted population with its actual population

## Simple Linear Regression

Simple Linear Regression is used to predict the **2017 population** using only the **1998 population** as the input feature.

### Input Feature

**Population 1998 Census**

### Target Variable

**Population 2017 Census**

The dataset was divided into:

- 80% Training Data
- 20% Testing Data

A `random_state` of 42 was used to make the train-test split reproducible.

### Simple Linear Regression Results

| Metric | Result |
|---|---:|
| R² | 0.9294 |
| MAE | 240,947.81 |
| RMSE | 851,078.15 |

### Result Interpretation

The Simple Linear Regression model achieved an **R² score of 0.9294**.

The **MAE** was approximately **240,948 people**, representing the average absolute difference between the actual and predicted population values.

The **RMSE** was approximately **851,078 people**.

## Model Comparison

The performance of both models was compared using R², MAE, and RMSE.

| Model | R² | MAE | RMSE |
|---|---:|---:|---:|
| Simple Linear Regression | 0.9294 | 240,947.81 | 851,078.15 |
| Multiple Linear Regression | 0.9300 | 236,373.71 | 847,423.46 |

### Comparison Result

The **Multiple Linear Regression model performs slightly better** than the Simple Linear Regression model on the selected test data.

It has:

- A slightly higher R² score
- A lower MAE
- A lower RMSE

This indicates that adding the **Change** and **Province** features provided a small improvement in prediction performance.

## Feature Coefficients

The Multiple Linear Regression model produced the following coefficients:

| Feature | Coefficient |
|---|---:|
| Population 1998 Census | 2.013490 |
| Change | 127,931.206417 |
| Azad Kashmir | 41,740.024212 |
| Balochistan | -24,958.314583 |
| Islamabad | -11,746.397818 |
| Khyber Pakhtunkhwa | 27,482.949437 |
| Punjab | -8,622.112339 |
| Sindh | -23,896.148909 |

### Coefficient Interpretation

The **Change** feature has the largest raw coefficient in the model.

A positive coefficient means that, while keeping the other features constant, an increase in that feature is associated with an increase in the predicted 2017 population.

A negative coefficient means that the model's predicted population decreases as that feature increases, while the other features remain constant.

However, raw coefficient values should not be directly treated as feature importance because the features are measured on different scales.

## Evaluation Metrics

### R² Score

R² measures how well the model explains the variation in the target variable. A higher R² value generally indicates better model performance.

### Mean Absolute Error (MAE)

MAE measures the average absolute difference between the actual and predicted values. A lower MAE indicates smaller prediction errors.

### Root Mean Squared Error (RMSE)

RMSE measures prediction error while giving more weight to larger errors. A lower RMSE indicates better prediction performance.

## Conclusion

This project demonstrates how Linear Regression can be used to predict the population of major cities in Pakistan.

The Simple Linear Regression model uses the **1998 population** as its only predictor, while the Multiple Linear Regression model uses **1998 population, population change, and province information**.

Based on the selected test data, the Multiple Linear Regression model performed slightly better than the Simple Linear Regression model.

The Multiple Regression model achieved an R² score of **0.9300**, compared with **0.9294** for Simple Linear Regression.

The model was also used to predict the population of Peshawar. The predicted population was approximately **1,974,760**, compared with the actual population of **1,970,042**, giving a difference of approximately **4,718 people**.

Overall, this project demonstrates how historical population data and additional features can be used to build, evaluate, compare, and apply regression models for population prediction.
